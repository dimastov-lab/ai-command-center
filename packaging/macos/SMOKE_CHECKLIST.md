# D4A — проверка unsigned macOS `.app`

Сборка: `dist/macos/AI Command Center.app`

- [ ] Запускается из Finder без активированного virtualenv.
- [ ] Открывается нативное окно, Dock icon и системное меню.
- [ ] Не запускается браузер и не открывается локальный HTTP-порт.
- [ ] Работают разделы «Главная», «Проекты» и «Настройки».
- [ ] Главная отображает реальные локальные данные либо понятное русское состояние ошибки.
- [ ] Тема, плотность, выбранный проект и геометрия окна сохраняются после перезапуска.
- [ ] Интерфейс остаётся русским в светлой и тёмной темах.
- [ ] В журнале Console нет необработанного traceback при штатном запуске/закрытии.

Сборка unsigned и unnotarized. Для внутреннего запуска при срабатывании
Gatekeeper: Finder → правый клик → «Открыть». Подпись и обход Gatekeeper
средствами сборки запрещены.
