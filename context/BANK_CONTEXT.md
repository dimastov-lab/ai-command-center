# Bank Strategy — Context Pack

Updated: 2026-07-15
Status: Active

## Objective

Implement the new management and strategy-execution process across the organization.

This is not a pilot and not a limited-scale rollout.

The Management Board must be able to review implementation progress every 30 days.

## Current Deliverable

A concise executive implementation and execution-control framework, preferably on one slide.

## Required Management Logic

The material must show:

- what changes immediately;
- what is completed by day 30;
- what is completed by day 60;
- what is completed by day 90;
- measurable milestones;
- named owners;
- current status;
- deviation from plan;
- corrective action;
- decisions required from the Management Board.

## Mandatory Rules

1. Do not describe the implementation as a pilot.
2. Do not propose unnecessary scaling stages.
3. Focus on full-process implementation.
4. Every milestone must be measurable.
5. Every metric must support a management decision.
6. Avoid decorative presentation language.
7. Show what the Board will see every 30 days.
8. Separate implementation progress from operating results.
9. Use executive language suitable for the Management Board.
10. Prefer one clear slide over a large presentation.

## Default Output Structure

- objective;
- 30/60/90-day implementation stages;
- monthly control metrics;
- responsible owners;
- deviations and corrective actions;
- Board decisions required.
