# D4B — проверка unsigned Windows 11 x64 сборки

Сборка: `dist\windows\AI Command Center\AI Command Center.exe`

Прогоняется на **чистой машине Windows 11 x64** — без установленного Python,
без `.venv`, без копии репозитория. Папку сборки копируем на неё целиком.

- [ ] Запускается двойным кликом из Проводника без активированного virtualenv.
- [ ] Открывается нативное окно, значок на панели задач и запись в Пуске.
- [ ] Не запускается браузер и не открывается локальный HTTP-порт.
- [ ] Позади окна не появляется консоль `cmd` (сборка windowed, `console=False`).
- [ ] Работают разделы «Главная», «Проекты» и «Настройки».
- [ ] Главная отображает реальные локальные данные либо понятное русское состояние ошибки.
- [ ] Тема, плотность, выбранный проект и геометрия окна сохраняются после перезапуска
      (на Windows `QSettings` пишет в реестр, а не в файл — проверяем именно там).
- [ ] Ширина окна после перезапуска восстанавливается точно (незакрытый пункт D1-гейта).
- [ ] Проводник открывается на нужном пути и выделяет файл (`reveal_in_file_manager`).
- [ ] Переключение системной темы Windows «Choose your mode» подхватывается на лету
      при режиме «Система».
- [ ] Интерфейс остаётся русским в светлой и тёмной темах.
- [ ] Выход происходит штатно, без диалога ошибки и без падения.

Сборка unsigned. При первом запуске SmartScreen покажет «Windows protected your PC» —
это ожидаемое поведение для неподписанной сборки (`PLATFORM_BEHAVIOR.md` §2), а не дефект:
«More info» → «Run anyway». Подпись и обход SmartScreen средствами сборки запрещены
(`DESKTOP_INCREMENT_1.md` §1, binding decision 12).
